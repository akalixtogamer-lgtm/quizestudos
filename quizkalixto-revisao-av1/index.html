pdSeries

Tipos de variáveis e manipulação de séries

Considere o trecho de código que simula a coleta de dados de um servidor:

import pandas as pd
dados = pd.Series(['200', '404', '200', '500', '200'], name='status_http')
latencias = pd.Series([12.5, 15.1, 12.8, 350.0, 13.2], name='ms')
Revisão relâmpago
  • Qualitativa nominal: categorias sem ordem (cor, status HTTP, sistema operacional). Número aqui é rótulo.
  • Quantitativa contínua: medida que aceita qualquer valor num intervalo (tempo, latência, peso).
  • Média × mediana: a média é sensível a valores extremos; a mediana (valor do meio) não.
  • Moda: o valor mais frequente. Em Pandas: .mode() ou .value_counts().

02Exercício 2
✦Amostra

Amostragem e reprodutibilidade

Você possui um DataFrame df_logs com 10.000 requisições e precisa extrair uma amostra para análise.

# Comando para gerar a amostra
amostra = df_logs.sample(n=100, random_state=42)
Revisão relâmpago
  • Amostra aleatória simples: todo elemento tem a mesma chance de ser sorteado.
  • Viés de seleção: a forma de escolher favorece um tipo de elemento (os primeiros, os mais recentes…).
  • Semente (seed): fixa o gerador pseudoaleatório, então o "sorteio" se repete igual.
  • Estratificada: divide a população em grupos (estratos) e sorteia dentro de cada um, na proporção de cada grupo.

03Exercício 3
kClasses

Distribuição de frequências e agrupamento

Considere uma lista de 50 idades de usuários de um sistema, variando de 18 a 80 anos.

Revisão relâmpago
  • Regra de Sturges: k = 1 + 3,322 · log₁₀(n), arredondado para cima.
  • Amplitude total: AT = máximo − mínimo. Amplitude de classe: h = AT ÷ k (arredonde para cima).
  • pd.cut(serie, bins=k) transforma cada valor no intervalo a que ele pertence.
  • serie.value_counts() conta quantas vezes cada valor (ou intervalo) aparece.
k = 1 + 3,322 · log₁₀(50) = 1 + 3,322 · 1,699 ≈ 6,64 → 7 classes
